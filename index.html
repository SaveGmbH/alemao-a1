2. W-FRAGEN — escolher a palavra certa

Primeiro descubra que informação você quer. Depois monte: W + verbo conjugado + pessoa.

WSignificadoQuando usarExemplo
Wie?como?nome, condição, maneiraWie heißt du?
Wo?onde?localizaçãoWo wohnst du?
Woher?de onde?origemWoher kommst du?
Was?o quê?atividade / profissão / coisaWas machst du beruflich?
Welche?qual/quais?escolher dentro de uma categoriaWelche Sprachen sprichst du?
Wie alt?quantos anos?idadeWie alt bist du?
Wer?quem?pessoaWer ist das?
Wie viele?quantos?quantidade contávelWie viele Kinder hast du?

WO

Wo + wohnst + du?
Lugar onde você está/mora.
Wo → in
Ich wohne in São Paulo.

WOHER

Woher + kommst + du?
Origem.
Woher → aus
Ich komme aus Brasilien.

WELCHE

Welche Sprachen + sprichst + du?
Não use “Was sprichst du?” para perguntar quais idiomas alguém fala.
Erros que já apareceram: “Wie kommst du?” → Woher kommst du? • “Wie Beruf bist du?” → Was bist du von Beruf? • “Was sprichst du?” → Welche Sprachen sprichst du?

3. CONJUGAÇÃO — seu principal ponto de treino

Você normalmente escolhe o verbo certo, mas às vezes usa a terminação de outra pessoa. Automatize pronome → forma verbal.

Verboichduer/sie/eswirihrSie/sie

Erro típico 1

✗ Ich kommst
✓ Ich komme
  • ich pede normalmente -e
  • du pede normalmente -st

Erro típico 2

✗ Woher kommst ihr?
✓ Woher kommt ihr?
  • ihr → kommt
  • não confundir com du → kommst

Erro típico 3

✗ Ich sprechen
✓ Ich spreche
  • ich spreche
  • du sprichst é irregular

5. NICHT / KEIN + JA / NEIN / DOCH

Aqui o objetivo é reconhecer o tipo de pergunta e escolher a resposta certa.

nicht

Ich bin nicht ledig.
Não sou solteiro.
Ich arbeite nicht in Berlin.
Não trabalho em Berlim.
Bist du nicht verheiratet?
Doch, ich bin verheiratet.

kein / keine / keinen

kein Kind — das Kind
keine Tochter — die Tochter
keinen Sohn — der Sohn
Hast du keine Tochter?
Doch, ich habe eine Tochter.

Pergunta positiva

Hast du eine Tochter?
→ Ja, ich habe eine Tochter.
→ Nein, ich habe keine Tochter.

Pergunta negativa

Hast du keine Tochter?
Se você tem uma filha:
→ Doch, ich habe eine Tochter.

Memorize 3 blocos

kein Kind
keine Tochter
keinen Sohn

11. ARTIGOS + OBJETOS + MÖBEL UND HAUS

Primeiro reconheça o gênero da palavra. Depois conecte o artigo definido, o indefinido e o negativo.

Artigos — regra-base

Masculino

DER → EIN → KEIN
der Tisch
Das ist ein Tisch.
Das ist kein Tisch.

Feminino

DIE → EINE → KEINE
die Lampe
Das ist eine Lampe.
Das ist keine Lampe.

Neutro

DAS → EIN → KEIN
das Buch
Das ist ein Buch.
Das ist kein Buch.
Plural: o artigo definido é die. Não existe artigo indefinido plural equivalente a “uns/umas” neste padrão. Para negar, use keine: die Tische → keine Tische.
Atenção: mais adiante aparece o acusativo masculino: ein Sohn → einen Sohn e kein Sohn → keinen Sohn. Por enquanto, memorize essa diferença como uma exceção importante do bloco com haben.
